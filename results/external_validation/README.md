# External Validation Summaries

This directory contains lightweight derived summaries used by Supplementary Section S6 of the manuscript.

- `external_validation_selection_flow.csv` and `.md`: source-record counts, exact identity-mapping counts, GABA-family counts and held-out or unresolved counts for the external audit panels.
- `drugbank_cold_drug_top120_rank_bin_control.csv` and `.md`: rank-bin background counts for the DrugBank cold-drug top-120 breadth audit.
- `drugbank_cold_drug_top120_breadth_category_counts.csv`: category counts for exact non-GABA mappings in the DrugBank cold-drug breadth audit.
- `drugbank_cold_drug_top120_non_gaba.csv`: leading exact non-GABA mappings used to summarize the breadth audit.

These files are derived from frozen case-study outputs and identity mappings. They are provided as audit summaries rather than as additional model-training data.
